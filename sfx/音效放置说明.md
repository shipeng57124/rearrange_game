# 游戏音效放置说明

音效目录：`I:\英语游戏\sfx`

这里放的是按钮、积木、提示、通关等 **游戏音效**。每个事件放一个文件，支持 MP3 或 WAV。下面列的是 MP3 文件名，使用 WAV 时把扩展名改成 `.wav`，例如 `select.wav`。不用改代码，不用上传到“听句子”区域，也不需要启动 IndexTTS。

| 文件名 | 完整路径示例 | 触发步骤 | 推荐内容 / 时长 |
|---|---|---|---|
| start.mp3 | I:\英语游戏\sfx\start.mp3 | 点击“开始冒险”、换例句、结算“下一个句子”，成功开始新挑战 | 欢快起步 / 0.3～1 秒 |
| select.mp3 | I:\英语游戏\sfx\select.mp3 | 点击待选词加入句子；拖动待选词并放进句子 | 积木落下、泡泡 / 0.05～0.3 秒 |

| grab.mp3 | I:\英语游戏\sfx\grab.mp3 | 开始拖动单词（移动超过小段距离），每次拖动只响一次 | 轻轻拿起 / 0.05～0.2 秒 |

| reset.mp3 | I:\英语游戏\sfx\reset.mp3 | 游戏区“再来一次”、结算“再玩一次” | 重新开始 / 0.3～0.8 秒 |

## 放入后的使用方式

1. 将音频按上表文件名放入本目录，例如 `success.mp3`、`select.wav`。不要只给文件改后缀，文件本身必须是真实的 MP3/WAV。
2. 刷新游戏，或打开右上角“音效”，点击“重新加载音效”。无需重启 Python。
3. 用音量滑块调节 **游戏音效**，默认 60%；静音或音量 0 会停止正在播放的音效。设置保存在当前浏览器。
4. “试听”播放 success 通关音效。文件未准备或损坏时，自动用内置轻柔提示音，不影响游戏。

同一事件同时有 `.mp3` 和 `.wav` 时优先 MP3。其他音效最多播放 2 秒，success 最多播放 6 秒，均不循环。快速连续操作会停止前一个音效，避免堆叠。朗读句子期间，新触发的音效会减弱到约 30%，朗读本身的音量不变。

不为输入文字、悬停或拖动过程中的每一帧播放声音。无效拖放只可能有拿起音效，不会误播落下音效。结算“下一个句子”只播 start，结算“再玩一次”只播 reset。

句子朗读音频仍通过“听句子 → 选择我的音频”添加，它与这些游戏音效独立。
